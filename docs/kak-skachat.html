Скачивание IX-Ray

Чтобы скачать IX-Ray, выполните следующие шаги:

  1. Перейдите на официальный сайт проекта или GitHub-репозиторий.
  2. Выберите последнюю стабильную версию.
  3. Скачайте архив с программой и распакуйте его в удобное место.

Для получения дополнительной информации посетите раздел Интеграции.

Обзор

Есть два способа скачать модули платформы IX-Ray (движок, редакторы, утилиты, плагины и т.д.):

  1. Скачать стабильную версию с релизов — рекомендовано для большинства пользователей.
  2. Скачать rolling версию — для тех, кому нужны самые свежие изменения.

Важно: Rolling-релизы — это билды, которые собираются после каждой фиксации изменений. Такие релизы могут содержать баги, недоработки, тестовые возможности и нестабильны. Только в полноценных релизах вы получаете полностью оттестированную и стабильную версию IX-Ray.

Что такое артефакт?

Артефакт — это любой файл или набор файлов, который создается в процессе автоматической сборки проекта. В нашем случае — это собранные файлы движка IX-Ray. Артефакты не хранятся в основном коде проекта. Они создаются "на лету" после каждого коммита. Их главная цель — дать вам возможность скачать последнюю версию платформы IX-Ray (engine, editors, utils, plugins), не собирая ее самостоятельно.

Способ 1: Скачивание стабильной версии (рекомендуется)

  1. Перейдите на страницу основного репозитория: ixray-1.6-stcop
  2. На главной странице репозитория найдите и нажмите на вкладку Releases.
  3. Вы попадете на страницу с последним стабильным релизом. Здесь вы можете выбрать game (игровой) или develep (для разработчиков, включает редакторы) билд в зависимости от своих потребностей.
  4. Просто нажмите на нужный файл для скачивания. Это самый простой и надежный способ.

Совет: Для скачивание релизов регистрация не обязательна!

Способ 2: Скачивание последней (rolling) версии через Actions

Шаг 1: Подготовка и вход в репозиторий

  1. Зайдите на сайт github.com.
  2. Авторизуйтесь (при необходимости создайте аккаунт).
  3. Перейдите по ссылке на официальный репозиторий: ixray-1.6-stcop
  4. Вы окажетесь на главной странице проекта.
  5. (Важно!) Обязательно поставьте Stars (звезду) репозиторию, чтобы поддержать разработчиков!

Шаг 2: Переход во вкладку "Actions"

В верхней части страницы, под названием репозитория, есть меню: Code, Issues, Pull requests, Discussions, Actions и др.

Нажмите на вкладку Actions.

Шаг 3: Поиск успешной сборки

Что мы видим? Мы попали в раздел с историей автоматических запусков (workflow). Слева — список этих воркфлоу (скриптов для сборки).

  1. В левой боковой панели выберите workflow (например, Build engine).
  2. Затем обратите внимание на центральный список. Самые свежие сборки находятся вверху.
  3. В столбце Branch выберите необходимую для вас ветку (мы рекомендуем использовать только default и develop).
  4. Найдите самый верхний запуск со значком ✅ (зеленая галочка) в столбце слева. Это последняя успешная сборка.

Шаг 4: Скачивание артефакта

  1. На странице запуска прокрутите вниз до раздела Artifacts.
  2. В списке найдите артефакт с названием engine-publish-windows-latest-x64-....
  3. Нажмите на название нужного артефакта, чтобы начать скачивание.

Предупреждение: Без авторизации вы не скачаете артефакт!

Установка

  1. Скачанный файл (для обоих способов) — это ZIP-архив
  2. Распакуйте его содержимое в папку с установленной игрой
  3. При запросе на замену файлов — согласитесь

Ключевое предупреждение: IX-Ray — это только движок. Он требует предустановленную лицензионную копию оригинальной игры.

Итог

  • Для стабильной игры: используйте Releases
  • Для тестирования новейших функций: используйте Actions (артефакты)
  • Не забудьте поддержать проект звездой (Stars)!
