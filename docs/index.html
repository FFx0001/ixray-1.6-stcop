IX-Ray Engine 1.6 (STCoP)

Модернизированный движок X-Ray 1.6 для S.T.A.L.K.E.R. — стабильный репозиторий

О проекте

IX-Ray — это форк X-Ray Engine 1.6, направленный на улучшение игрового и девелоперского опыта, исправление багов оригинала и расширение возможностей для модмейкеров.

  • Поддержка x64, CMake, DirectX 9.0c/11
  • Улучшенная производительность и FPS
  • Расширенные возможности для моддинга
  • Поддержка DLTX, XMLOverride, TTF-шрифтов, BC7, DLSS, FSR2
  • Встроенные инструменты отладки и расширенный UI
